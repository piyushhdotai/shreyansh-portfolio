# Shreyansh Singh — Portfolio

A retro, 90s-homepage-style portfolio built with React + Vite.

## Run it

```bash
npm install
npm run dev      # local dev server
npm run build    # production build in dist/
```

## Edit content

All text, links, stats, projects and certificates live in `src/data.js`.
Set `links.email` there to show the "E-mail me" button.
The profile photo is imported from the `images/` folder.
